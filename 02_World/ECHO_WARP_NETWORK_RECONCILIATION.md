# Echo-Warp Network Reconciliation

Status: **APPROVED-PENDING**
Implementation: **NOT YET VERIFIED**

## Purpose

Rebearth may use a restored warp/portal network to connect distant regions, Theaters, Sanctuary routes, sky routes, submerged routes, and post-game anomaly paths without replacing normal exploration.

The network exists to support the main loop:

**Explore → Protect → Restore → Unlock Route → Revisit → Expand Rebearth**

## Canon-safe portal classes

Working portal classes from historical intake:

- Sanctuary Gates
- Theater Gates
- Spire Portals
- Rootgates
- Tidegates
- Forge-Lifts
- Sky-Bridge Portals
- Moonwells
- Chorus Doors
- Abyssal Seams

These are route classes or working presentation names. Every final public-facing name must pass the originality and continuity check before CANON lock.

## Portal record requirements

Every portal/warp record must define:

- stable PortalID
- source region and destination region
- unlock condition
- visual state
- story prerequisite
- restoration prerequisite
- corruption/Blight state
- fast-travel eligibility
- destination safety state
- world-state delta after restoration
- save flag and version
- failure/locked state
- valid fallback destination

## World integration

The portal network must connect to the current Rebearth map rather than create a second geography. Portal placement should be reconciled against Echohearts City, Vespera Basin, Solis Reach, Caldera Coast, Neon Sea, Shifting Dunes, Glacial Spires, Veridian Isles, Paleon Depths and other approved regions.

Portals do not erase traversal systems. Swimming, deep-water partners, climbing, Hookline use, flight-capable Eco-Kin, Field Rig travel, and normal overland exploration remain meaningful.

## Restoration rule

A damaged portal cannot become a clean convenience button simply because the player discovers it. Activation requires an authored combination of story progress, regional restoration, A.E.G.I.S. validation and safe destination state.

Restoring a portal should produce a visible Rebearth consequence such as:

- migration route reopening
- aid/rescue access
- lower travel risk
- restored rainfall or airflow link
- Sanctuary supply connection
- new mission path
- new Theater access
- faction pressure change
- Eco-Kin population response

## Multiplayer / authority rule

Fast travel is server-authoritative. Clients request a stable PortalID only. The server resolves unlock state, world state, party eligibility, destination, cooldown/rules and any travel cost.

Before relocation, the destination must be valid and its required World Partition cells/data layers must be ready. No client-provided raw coordinate teleport is accepted.

## Naming/IP firewall

Historical outside-franchise names, dungeon names, bosses, tournament names, mechanics, copyrighted creature identities and copied progression terminology are **REFERENCE-ONLY** and must not appear in publication-facing Echohearts content.

Only transferable design principles may survive: readable route gating, region identity, challenge escalation, traversal variety, boss mechanics, replayability and world-state consequences.
