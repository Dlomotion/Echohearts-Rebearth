# Historical Eco-Kin Batch Reconciliation Plan

© 2026 Into Deep Studios and Donta L. Owens. All rights reserved.

## Goal
Turn the large historical Eco-Kin Creation Batch archive into a controlled, high-quality source library without flooding canon with duplicates, conflicting elements, repeated Legendary lines, or unreviewed art.

## Work Cadence
Process small bounded groups. Do not attempt to canonize the entire archive in one pass.

Recommended pass size: **5–10 historical names per review session**.

## Pass Order
### Pass A — Exact Name Collisions
Start with repeated names and families already visible in the archive:
- Veripaw
- Verithorn
- Aerowisp
- Shadowfin / Shadowlurk
- Glacifin / Frosttusk
- Luminix / Lumoray
- Solarion / Solrider
- Stonequill

Deliverable: keep / merge / rename / retire / reject decision for each collision family.

### Pass B — Canon Element Migration
For surviving candidates, migrate old element labels into the twelve-element system. Record the rationale rather than replacing terminology mechanically.

### Pass C — Ecology & Role Deduplication
Compare repeated roles such as solar guardians, luminous healers, swamp controllers, stone tanks, reef defenders, aerial strikers, and abyssal ambushers. Every survivor must gain a distinct behavior loop and ecological reason to exist.

### Pass D — Growth/Form Migration
Convert historical `Chil-Kin → Mega Kin → Ultimate Kin` and mutation language into current Growth Rite/form logic. Remove forced-evolution implications.

### Pass E — Art Recovery
Recover only the source images for candidates still alive after design QA. Run anatomy, silhouette, artifact, originality/IP, VFX/accessibility, and animation-feasibility review.

### Pass F — Permanent Identity
Assign EcoKinID/EchoprintID only after all previous gates pass.

## Daily Output
Each reconciliation session should produce:
1. one AI Mistake Patch / Continuity QA note,
2. 5–10 reviewed historical candidates,
3. collision decisions,
4. current element mapping decisions,
5. status updates,
6. art-recovery requests only where justified,
7. exact next group to review.

## Status Vocabulary
- CANON
- APPROVED-PENDING
- MERGED / RENAMED
- RETIRED / REFERENCE-ONLY
- REJECTED

## Stop Conditions
Do not promote an entry when:
- the source art or description is too incomplete to identify the concept,
- it duplicates a stronger current Eco-Kin,
- the name is too close to another entry or outside IP,
- anatomy cannot be made coherent without replacing the concept,
- its role is redundant and no meaningful ecological distinction exists,
- it depends on retired capture/fusion/forced-work systems,
- its Legendary status exists only because every batch needed a Legendary finale.

## Heart Statement Check
The surviving roster should become smaller, stronger, easier to remember, and more alive. Historical volume is not the goal. Every approved Eco-Kin should help prove:
- This world needs me.
- These Eco-Kin are alive.
- My choices changed Rebearth.
