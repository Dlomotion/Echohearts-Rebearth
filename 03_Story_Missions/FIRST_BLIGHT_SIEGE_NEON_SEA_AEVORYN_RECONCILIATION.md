## Purpose

## Mission Candidate A — When the Farm Learned Fear
- Region: Vespera Basin / first Sanctuary plot
- Story role: first proof that restoration attracts pressure and responsibility
- Taught systems: Sanctuary defense, partner protection, Purity support, visible world-state consequence
- Core objective: protect crops, shelter, archive data and a corrupted Dandelion while avoiding unnecessary destruction
- Ethical branch: cleanse carefully / protect partner first / accept infrastructure cost
- Required world delta: surviving crops, damaged or restored support structures, Dandelion state, NPC reactions
- Required persistence: outcome flag + Sanctuary damage state + Dandelion trust/state
- Current risk: source uses forced-garrison/worker language that must be replaced by voluntary partner support

## Mission Candidate B — Where the Ocean Forgot Its Color
- Region: Neon Sea / Azuredeep approach
- Story role: teach deep-water survival and ecosystem restoration at scale
- Taught systems: swimming, aquatic partner support, pressure safety, reef restoration, underwater routes
- Candidate Eco-Kin: SeaShock, SeaShield, Jelly Jellyfish, Orcanize
- Candidate villain: Vance, pending faction/canon review
- Required world delta: cleared routes, restored reef color, safer traversal, changed migration, improved Sanctuary access
- Required persistence: reef restoration flags + route unlocks + faction pressure state

## Mission Candidate C — The Drill That Bit the Planet
- Region: Neon Sea extraction zone
- Story role: first major extraction-machine boss where environmental victory matters more than loot
- Phases to preserve conceptually: disable anchors → survive hazards → expose machine core → use partner abilities → restoration finale
- Required terminal proof: machine shutdown event + reef recovery state
- Current risk: source references Demon-type corruption and fixed partner requirements; these must be reviewed so players are not hard-locked to one exact roster unless narratively justified

## Mission Candidate E — The Tower That Counted Backward
- Landmark: Clockspire of Aevoryn
- Story role: memory/time wound, not a generic grind tower
- Taught systems: Time-Echo observation, memory puzzles, safe partner recovery, consequence reading
- Required world delta: unlock Time-Echo understanding, memory-route access and future-choice context
- Required persistence: Aevoryn proof/lesson state, unlocked memory traversal, no unrestricted rewind exploit
- Current risk: legacy progression branch names remain proposal until current Keeper tree review

## Acceptance Criteria For Promotion
Each mission must have:
- prerequisite
- trigger
- recommended level and danger tier
- objectives and completion steps
- taught system
- authoritative completion proof
- visible Rebearth delta
- Eco-Kin/NPC/faction consequence
- reward/unlock
- persistent save flag
- ethical alternative
- failure/partial state
- valid successor mission

No mission is CANON until these are resolved against the current chapter grid.
