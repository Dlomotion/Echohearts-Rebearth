# Repost Intake & Routing Rule

Status: **ACTIVE PRODUCTION RULE**

Whenever project material is reposted from an older chat, screenshot, document, image board, code block, or prior generated answer, do not paste it into canon unchanged.

## Required processing order

1. Identify source and subject.
2. Remove accidental duplicate text and repeated assistant claims.
3. Run AI Mistake Patch / Continuity QA.
4. Compare against current locked names, locations, systems, factions, stats, elements, and character identities.
5. Fix spelling/name drift and merge duplicate characters/systems.
6. Mark unsafe outside-IP resemblance for redesign.
7. Correct anatomy/artifacts for visual assets.
8. Correct unsupported engineering claims and obsolete APIs.
9. Route useful material into its proper folder.
10. Add a story/gameplay connection so no concept floats without purpose.
11. Add implementation/QA requirements.
12. Assign status: CANON, APPROVED-PENDING, MERGED/RENAMED, REFERENCE-ONLY, RETIRED, NOT YET VERIFIED, VERIFIED.

## Folder routing

- Story/NPC/lore → `01_Story`
- Regions/habitats/landmarks → `02_World`
- Eco-Kin identity/biology/roster → `03_EcoKin_Dex`
- Mechanics/progression/economy/bonding → `04_Systems`
- Missions/encounters/levels → `05_Levels`
- UI/HUD/EcoDex/A.E.G.I.S. screens → `06_UI_UX`
- Images/design briefs/model sheets → `07_Art`
- Music/VO/creature sound → `08_Audio`
- Unreal/C++/Blueprint/networking/save/tests → `09_Technical`
- Backlog/QA/provenance/assignments → `10_Production`
- Public-ready material only → `11_Publication`
- Contradictions/outside references/retired systems → `99_Reference_Retired_Needs_Redesign`

## Definition of “locked in”

“Locked in” means the material is accepted into the official Echohearts workflow and protected from being lost. It does **not** mean every pasted detail automatically becomes canon or verified code. Contradictions are corrected, duplicates are merged, and technical claims still require evidence.

## Daily assignment rule

Every daily production pass should select at least one concrete engineering task and one concrete game/story/art task from the routed backlog, complete what dependencies allow, record evidence, and carry unfinished work forward.
