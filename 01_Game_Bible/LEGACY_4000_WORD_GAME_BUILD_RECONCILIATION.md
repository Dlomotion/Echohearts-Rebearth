## Why this file exists
A historical 4000-word game build contains useful pillars but also older systems that conflict with current Echohearts canon. This file preserves the useful architecture while preventing legacy rules from overwriting the current source of truth.

## Strong ideas preserved
- Rebearth as a living world whose condition changes mechanically.
- Eco-Kin as sentient partners with temperament and memory.
- A.E.G.I.S. as the core field interface.
- Exploration → study → restore/exploit choice → combat → return/rebuild loop.
- World-state consequences affecting biomes, NPCs, crafting, bosses and endings.
- Sanctuary/city progression.
- Timeline/era presentation.
- Faction reputation and meaningful choices.
- Gardening, fishing, resource gathering and research.
- Boss rules that require adaptation rather than pure damage races.
- STARZ*/Saviors and Ancient Tech Wars as expansion material.
- Vertical-slice-first production thinking.

## Current canon overrides

### Player Identity
Legacy: Agent.
Current: Frequency Tamer / Echoheart / Core-Binder, with Veridian Keeper where canon-compatible.

### Combat
Legacy: main turn-based timeline combat, four active + two reserves.
Current: real-time third-person campaign combat. Tactical/turn-based play belongs in Harmony Circuit, Resonance Arena, EchoDeck and training simulations.

### Elements
Legacy: 18-element system including Frost, Fungi, Toxic, Crystal, Shadow, Sound, Gravity, Time and Plasma as elements.
Current locked elements:
Solar, Lunar, Hydro, Magma, Aero, Flora, Volt, Terra, Iron/Tech, Spirit, Chaos, Radiant.

Legacy labels may survive only as statuses, materials, biome traits, sub-affinities, VFX language or retired terminology.

### Vaccine / Data / Virus
Historical strategic layer is reference-only. It must not become a second public typing system unless a future canon review explicitly promotes a compatible version.

### Public Stats
Legacy generic combat stats/runes are not public core stats.
Current public core stats:
Vibrance, Density, Harmony, Purity.

### Bonding
Legacy eco-traps/catching/summon loop is replaced by:
Observe → Protect → Calm → Kindle → Bond / Release / Defer.

### Eco-Kin Agency
No creature trading, forced work, forced breeding, forced evolution, sentient crafting ingredients, living batteries or capture inventory.

### World Simulation
Legacy Nuclear Pillar is not a separate locked world engine.
Its useful functions must map into existing Circle Balance Gauge, regional world-state data, Blight pressure, Purity, restoration state, faction pressure, D.A.H.L.I.A. World Memory Director and story progression.

### Endings
Legacy three endings are superseded by the current four families:
- Heal / Order
- Break / Severance
- Balance / True Rebirth
- Transcend / Star Rewrite
plus five secret-variant slots awaiting exact canon conditions.

## Reconciled Core Loop
1. Explore a damaged region.
2. Scan and study its ecology, history and current threat.
3. Protect life and decide how aggressively to intervene.
4. Fight hostile forces in real time.
5. Calm, treat and Kindle compatible Eco-Kin.
6. Repair ecosystem and infrastructure.
7. Return to Sanctuary / Echohearts City to research, craft, build and reconnect communities.
8. Observe the persistent world consequence.
9. Unlock the next route, chapter or restoration problem.

## World-State Model
Do not create a duplicate CLI/Nuclear Pillar manager.
Use one authoritative world-state model that can expose:
- regional Vibrance
- regional Density
- regional Harmony
- regional Purity
- Blight pressure
- over-purification risk
- faction pressure
- Eco-Kin trust
- NPC stability
- Sanctuary support
- persistent mission/world flags

## A.E.G.I.S. Role
Current A.E.G.I.S. functions may include:
- scan
- field survival support
- Kindling support
- partner commands
- environmental analysis
- Ancient Tech interaction
- Timeline Map access
- safe restoration tools

Do not restore old trap/capture authority.

## Faction Treatment
Historical faction names from older GDDs must be compared with the current faction registry before promotion.
No older faction may silently replace Alliance of Freedom, Civil Rangers, Corporate Muscles, Brotherhood, current Meridian remnants or other locked groups.

## MVP Interpretation
The useful production lesson from the historical MVP is preserved:
prove the game with one excellent vertical slice before scaling the whole universe.

A valid current vertical slice should demonstrate:
- one visually distinct region
- one Sanctuary loop
- A.E.G.I.S. scanning
- one Kindling encounter
- real-time combat
- one restoration before/after state
- one meaningful choice with persistent consequence
- one dungeon/ruin problem
- one boss or high-pressure rescue
- one EcoDex learning loop
- one world-state save/reload proof

## Publication Rule
Historical phrasing such as capture, trap, tactical main combat, 18 elements, Nuclear Pillar, creature trading, forced breeding/genetics and Virus/Data/Vaccine typing must not appear as current public canon unless separately approved.
