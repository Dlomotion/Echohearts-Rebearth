# LEGACY MUTATION / FUSION / CAPTURE REFERENCE — RETIRED

**Status:** REFERENCE-ONLY / RETIRED

This file preserves the useful design questions from a reposted systems packet while explicitly retiring mechanics that conflict with Echohearts canon, originality requirements, or technical direction.

## External-franchise/reference material

The repost discussed progression patterns associated with Aniimo, Digimon and Pokémon. These references are useful only at the level of broad design questions such as:

- linear vs branching growth;
- condition-based transformations;
- care and environment affecting progression;
- role changes across forms;
- tournament/status progression;
- readable evolution UI.

Echohearts must not copy names, tier structures, UI layouts, signature mechanics, formulas, creatures, stage labels, item logic, or progression rules from those franchises.

## Retired mutation terminology

Retired / replaced:

- Mutation Tree → **Growth Rites / Resonance Branches**
- Alpha / Beta / Gamma mutation → authored branch families such as **Vanguard / Bastion / Chorus / Wayfinder / Primal / Restored**
- Somatic Milestone → **Resonance Milestone**
- Soma Shard → **Resonance Shard**
- Amniotic Serum → **Reharmonization Rite** where reversible adaptation is appropriate
- Genetic Instability → **Resonance Strain / Spirit Load**
- Bio / Kinetic / Matter element families → current 12 core elements only

## Retired DNA fusion / donor consumption

The following mechanics are prohibited for player progression:

- consuming a donor Eco-Kin;
- permanent DNA splicing between sentient Eco-Kin;
- body fusion;
- species identity overwrite;
- forced hybridization;
- harvesting genome material from defeated Eco-Kin;
- unrestricted trait copying;
- unrestricted cross-element skill theft.

Ethical replacements:

- **Resonance Trait Infusion**
- **Bio-Synergy Weaving**
- **Command Sync**
- **Harmonic Overdrive**
- **Primal Reversion**
- authored training techniques

All preserve separate identities and require willingness / trust where applicable.

## Retired capture/trapping ownership loop

The following are not player capture progression:

- snares around limbs;
- pit traps for ownership;
- containment cages;
- cryo latches to suppress an Eco-Kin;
- insulated cages for Electro/Volt Eco-Kin;
- baiting sentient Eco-Kin into cages;
- Stress Gauge exhaustion to secure a catch;
- harpoon ballistae;
- induction cages;
- pheromone lures that force a Sovereign into containment.

Useful ideas retained in corrected form:

- ecological tracking;
- spoor and habitat clues;
- scent masking;
- food freshness/spoilage as ecology/survival;
- safe food/water placement;
- Rescue/Recovery equipment;
- Purity Field Rings;
- Resonance Anchors;
- Listening Posts;
- Open-Gate Recovery Pens;
- evacuation and route-control tools.

The field relationship remains:

**Observe → Protect → Calm → Kindle → Bond / Release / Defer**

## Retired public stat replacements

The pasted HP / ATK / Physical DEF / Magic DEF / Regen / Break system is not the Echohearts public stat model.

Public Eco-Kin stats remain:

- Vibrance
- Density
- Harmony
- Purity

Internal runtime combat values may be derived from those stats and authored abilities, but should not create a competing public sheet.

## Retired universal Champion evolution tier

`Champion` is not a universal biological evolution stage.

Echohearts uses **Championship Status / Resonance Circuit Standing** for competitive achievement, separate from Eco-Kin Growth Rites.

Winning sanctioned championship fights can increase standing, unlock titles, cosmetics, invitations, trials and competitive content without forcing a species transformation.

## Retired raw code claims

The pasted Python-style classes for `ParticlePoolController`, `EcoKinData`, `AlphaEcoKinComponent` and `ChampionEvolutionNode` are conceptual pseudocode only.

They are not Unreal Engine 5.8 production code, have not been compiled, and are not VERIFIED.

Do not port them literally. Implementation waits for the active technical gates and should use the actual UE project architecture, current Epic documentation and measured requirements.
