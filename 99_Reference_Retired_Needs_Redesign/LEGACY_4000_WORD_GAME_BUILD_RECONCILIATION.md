## Why this file exists

A historical game-build draft contains useful pillars but also older systems that conflict with current Echohearts canon. This file preserves the useful architecture while preventing legacy rules from overwriting the active source of truth.

## Current source-of-truth overrides

### Naming

Public creature term: **Eco-Kin**.

Technical/data identifier form: **EcoKin**.

Singular possessive: **Eco-Kin's**.

See `00_Canon_Lock/ECOKIN_NAMING_STANDARD.md`.

### Player identity

Historical labels such as Agent, Core-Binder, or Frequency Tamer may survive in archival context, but the active front-facing profession is **Tamer of Beasts**. **Veridian Keeper** remains the ethical/restoration discipline.

### Combat

Historical main turn-based combat is retired from the campaign. The main campaign uses real-time third-person action combat. Tactical or turn-based systems belong only in approved Arena/EchoDeck/simulation contexts.

### Bonding

Historical trap/catching/ownership loops are retired from normal player progression.

### Eco-Kin agency

No creature trading, forced work, forced breeding, forced evolution, sentient crafting ingredients, living batteries, inventory-object storage, or player/Eco-Kin body fusion.

### World simulation

Do not create a duplicate world-state engine merely because an older document used another name. World-state features must reconcile into the current Rebearth simulation, regional restoration, Blight pressure, Purity, faction pressure, Eco-Kin memory/trust, NPC state, Sanctuary state, and story progression.

## Strong ideas preserved

- Rebearth as a living world whose condition changes mechanically.
- Eco-Kin as sentient partners with temperament and memory.
- A.E.G.I.S. as the core field interface.
- Exploration → study → protect/restore → combat or crisis resolution → return/rebuild loop.
- Persistent biome, NPC, crafting, boss, and ending consequences.
- Sanctuary/city progression.
- Timeline/era presentation where continuity supports it.
- Faction reputation and meaningful choices.
- Gardening, fishing, resource gathering, and research.
- Boss rules that require adaptation rather than pure damage races.
- STARZ*/Saviors and Ancient Tech material when reconciled through current canon.
- Vertical-slice-first production thinking.

## Reconciled core loop

1. Explore a damaged region.
2. Scan and study its ecology, history, and current threat.
3. Protect life and decide how aggressively to intervene.
4. Fight hostile forces in real time when combat is necessary.
5. Calm, treat, relocate, or Kindle compatible Eco-Kin.
6. Repair ecosystem and infrastructure.
7. Return to Sanctuary / Echohearts City to research, craft, build, and reconnect communities.
8. Observe the persistent world consequence.
9. Unlock the next route, chapter, or restoration problem.

## MVP interpretation

The useful lesson remains: prove the game with one excellent vertical slice before scaling the whole universe.

A valid current vertical slice should demonstrate:

- one visually distinct region
- one Sanctuary loop
- A.E.G.I.S. scanning
- one Kindling encounter
- real-time combat
- one restoration before/after state
- one meaningful persistent choice
- one ruin/dungeon problem
- one boss or high-pressure rescue
- one EcoDex learning loop
- one world-state save/reload proof
