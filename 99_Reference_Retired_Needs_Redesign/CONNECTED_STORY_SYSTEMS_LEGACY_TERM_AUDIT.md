## Terms / Concepts Requiring Review
- Garrison Eco-Kin → replace with voluntary Sanctuary defender/partner support language.
- Worker Eco-Kin morale / farm worker → replace with Sanctuary Aptitude / voluntary helper behavior.
- Morrowind Rift → already corrected toward Aevoryn / Time-Echo language.
- Demon-type corruption → legacy taxonomy; map only if current class system supports it.
- Echo-Heart Finisher / Echoheart Resonator → verify against current A.E.G.I.S./Link Device terminology before canon use.
- Global Purity Map → can survive as UI concept only if it uses current world-state model and does not reduce all ecology to one meter.
- Starvault Spires → proposal; check overlap with current Solis Reach, Veridian Isles, sky landmarks, STARZ* and Savior material.
- Alien-type Eco-Kin → review against current Kin/Humanoid/Celestial/Spirit and world-origin classifications.
- Blightbreaker / Lifewarden / Gatewalker → proposed Keeper progression labels only.
- Harmonic Synchrony → verify naming against Command Sync / Partner Assist / Harmonic Overdrive.
- Oil-static → acceptable as environmental presentation term only if it maps cleanly to Blight/Data Virus effects.
- Sanctuary defense assignments → cannot become forced work.

## System Collisions To Avoid
- Seasonal Pulse must not duplicate the Rebirth Seasonal Clock.
- Migration logic must not duplicate the World Memory Director.
- Time-Echo progression must not create unrestricted time travel.
- Dreadlion Bloom must not duplicate Dandelion's established rescue story unless intentionally merged.
- Vance must not overlap another extraction villain without a distinct worldview and faction role.
- Starvault Spires must not become a second primary sky-world hierarchy.

## Canon Promotion Rule
A legacy term may be APPROVED, MERGED/RENAMED, RETIRED/REFERENCE-ONLY or REJECTED. No historical wording is assumed canon solely because it appeared in an old story draft.
