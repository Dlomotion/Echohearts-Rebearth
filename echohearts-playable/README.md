# EchoHearts — Playable Terraria-Style Adventure

Open `index.html` in a browser to play the single-file playable version built in Muse: mine/chop, collect resources, build, survive day/night, fight slimes, mischievous imps, zombies and flying eyes, and summon the boss The Echo Devourer to win an Echo Heart.

Source projects:
- `../echohearts-rebirth-game/` — 2D web game source (HTML/CSS/JS)
- `../echohearts-rebirth-3d/` — 3D C++ game source (raylib + CMake)
