# Eligibility Verdict: Processing Foundation 2027 Fellowship — NO-FIT

**Verdict: Echohearts is not eligible. Two independent published rules fail.**

This is not legal advice. Nothing has been submitted anywhere. Rules below are
quoted/paraphrased from the fellowship's published 2027 information (read 2026-10-19;
nominations close November 1, 2026, 11:59 p.m. PST).

## Rule 1 — Location (FAILS)

> "Gaming the System: Los Angeles, California, with a hybrid working arrangement."
> "Game makers based in Los Angeles. Creative coders based in Los Angeles.
> Educators based in Los Angeles."

You are based in Chicago, Illinois. The Gaming the System track — the only track
matching game development — requires the fellow to be LA-based with in-person
participation (including an in-person summer intensive in Los Angeles). **Fail.**

## Rule 2 — Mandatory open-source project requirement (FAILS)

> "Every project proposed for the 2027 Processing Foundation Fellowship must build
> on one of the foundation's designated open-source projects."
> Designated projects: p5.js, p5.js Editor, Processing 4.x, Processing Development
> Environment, Processing 5.0 Rust R&D, Experimental Python Package.

Echohearts: Rebearth is built on Unreal Engine 5 — a proprietary Epic Games engine,
not a Processing Foundation open-source project. The fellowship exists to
"strengthen and expand the existing creative coding ecosystem," not to fund
unrelated projects. No honest reading of an UE5 action RPG satisfies this rule.
**Fail.**

## Rules that PASS (for the record)

- **US-based:** "Nominees must be based in the United States." You pass (Chicago, IL).
- **Professional background:** "Game making, creative coding, or education" — you pass.
- **No degree requirement** — no barrier stated.

Two failures are dispositive. One would be enough.

## Honest workaround (not a fudge)

The **Collective Intelligence** track is remote, anywhere in the US — so location
passes there. But the open-source-project requirement applies to *every* track.
Echohearts still fails it.

What *could* fit, honestly, in a future year: a **separate** project — e.g., a
p5.js-based open-source toolkit teaching game design to underserved Chicago youth,
run through your foundation's youth tech-training mission. That would satisfy the
LA-independent track, the open-source rule, and the community-participation
emphasis. It is a different project from Echohearts, and it should be pitched as one.

## Bottom line

**Do not chase this fellowship with Echohearts.** The LA requirement and the
Processing open-source requirement each independently disqualify it, and neither
can be worked around without misrepresenting the project. Your energy is better
spent on the game and on grants that fit an Illinois youth nonprofit (see the
foundation conversion packet).
