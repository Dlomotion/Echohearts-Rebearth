# Awaiting Population

This folder is reserved and intentionally empty.

- `shared/ui/` — interface art: menus, HUD, A.E.G.I.S. device screens, type icons.
- `shared/worlds/` — region and environment art: Rebearth vistas, Sanctuary views.

When art exists for these, file it here via `file_assets.py` (extend the script
rather than hand-filing), and replace this note with an index.
