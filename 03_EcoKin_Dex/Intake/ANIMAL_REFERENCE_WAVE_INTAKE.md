# Animal Reference Wave — Eco-Kin Intake

Status: **REFERENCE-ONLY → concept development**.

These animal references are biological/anatomy starting points. They are not finished Eco-Kin until naming, silhouette, element, ecology, role, animation, and originality review are complete.

## Reference set

1. **Okapi** — rare forest guardian/scout direction. Preserve true ungulate proportions, split hoof anatomy, long tongue behavior, striped hindquarters, cautious forest movement.
2. **Echidna / spiny anteater** — compact digging specialist. Preserve low body, powerful forelimbs, spines, snout, digging gait, defensive curl/tuck behavior.
3. **Coati** — curious climbing/foraging scout. Preserve long mobile snout, ringed tail, dexterous paws, group/social behavior, arboreal agility.
4. **Patagonian mara** — open-country runner/herd Eco-Kin. Preserve long limbs, cursorial posture, alert ears, pair/herd behavior.
5. **Tarsier** — nocturnal tree-climber/scout. Preserve giant eyes, grasping digits, vertical-cling-and-leap locomotion, small primate body plan.
6. **Bat-eared fox** — desert/plains sound-tracker. Preserve oversized ears, slender canid body, insect-foraging behavior, heat-aware movement.

## Franchise translation rules

- Keep these as **true animal Eco-Kin**, not automatic humanoids.
- Do not add extra limbs, hands, fingers, wings, horns, or armor that breaks the underlying body plan unless a specific growth/form concept justifies it.
- Ancient Tech equipment must fit safely around anatomy and movement.
- STARZ* or crystalline effects are visual/sub-affinity language unless separately approved in gameplay data.
- Each line needs a unique silhouette, locomotion set, cry/audio profile, habitat, ecology role, Sanctuary aptitude, battle role, and story reason.
- Real animal reference is for anatomy and behavior study, not copying another creature franchise’s design language.

## Development routing

Each candidate must pass:

`animal research → silhouette thumbnails → originality/DNA audit → anatomy QA → name audit → element/stat proposal → combat/support role → ecology → growth line → A.E.G.I.S. interactions → rig/animation needs → VFX/audio → UE5 data → balance/QA`

No candidate in this intake is automatically CANON merely because art was generated.
