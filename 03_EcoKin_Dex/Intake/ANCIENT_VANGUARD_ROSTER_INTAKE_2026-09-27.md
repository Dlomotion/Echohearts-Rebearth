## Identity rules

- Each name represents one identity only unless later evidence proves an intentional evolution/form relationship.
- `The Fracture-Wall`, `The Overheated Engine`, `The Lightning Void`, `The Blighted Monolith`, and `The Void Specter` are **corrupted states**, not new species.
- Chronicle/time-echo duplicates are temporal signatures, not duplicate permanent beings.
- Defeating a corrupted manifestation restores/cleanses the archive state; it does not authorize body harvesting.
- If one of these identities is later mapped to an existing permanent EcoKinID, all forms/states inherit that parent's Echoprint/history rather than creating another slot.
