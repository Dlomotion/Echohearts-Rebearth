## Purpose
Preserve the large historical Eco-Kin image-creation batch without losing user-authored names or approved visual intent, while preventing generated captions, typos, duplicates, outside-IP echoes and obsolete evolution/element systems from becoming accidental canon.

This file is an intake registry, not a second Dex.

## Governing rule
For each historical image/name:
`SOURCE → identity match → newest user correction → duplicate/alias audit → originality/IP audit → anatomy/body-plan audit → locked-element mapping → V/D/H/P translation → ecology/story placement → art status → canon decision`

Existing permanent EcoKinID/Echoprint identity always wins over a newly inferred duplicate.

## Art correction rules from user feedback
The user explicitly rejected the pattern of redesigning Eco-Kin away from the established visual direction and asked that bad generations not replace the intended set.

Therefore:
- preserve the core style/composition/identity of an approved image when fixing it;
- make only the requested correction unless a broader redesign is explicitly requested;
- latest explicit naming correction wins;
- malformed/rejected generations go to `99_Reference_Retired_Needs_Redesign`;
- do not delete evidence needed for provenance/traceability, but do not keep rejected images in the active canon-art slot;
- generated-image titles are not canon evidence by themselves.
