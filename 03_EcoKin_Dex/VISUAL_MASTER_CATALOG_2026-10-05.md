## Method notes

- **Names are verbatim.** No species renamed, no spellings "fixed." Variants are recorded as-is (e.g. `Pharoah / Pharaoh`, `Skryaxis`, `Braziliana`).
- **Dex ID column is never invented.** Repo-wide check: **zero** permanent `EcoKinID`s are assigned in any reconciled source — every entry is UNASSIGNED / NOT YET ASSIGNED.
- **Order column:** the five Orders (Zoa/Flora/Myko/Proto/Monera) come from locked canon, not from these repo files. Where I inferred an Order from body plan/origin it is marked **PROPOSED**. Where the source gives no usable origin it is marked **Unstated in source** (mineral/stone/anomaly/humanoid cases flagged for 10_Production rather than forced into an Order).
- **Art-manifest status mapping:** `CANON IDENTITY` / `ESTABLISHED PRODUCTION REFERENCE` → Approved Canon Art; historical/source art used as reference → Reference/Inspiration Only; explicit retirements and malformed generations → Rejected-Retired (kept listed for traceability); flagged duplicates → Duplicate Review; everything else → Unknown.
- Dense name inventories (§3.1–§3.8) are preserved as verbatim grouped lists rather than one table row per bare name; every name appears exactly as written in its source.
