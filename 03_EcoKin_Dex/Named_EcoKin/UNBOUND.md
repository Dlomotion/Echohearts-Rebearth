# Unbound — Production Reference Record

Status: APPROVED-PENDING / ESTABLISHED PRODUCTION REFERENCE

## Identity
- Name: Unbound
- Category direction: Humanoid-Kin guardian
- Working elements: Aero + Spirit
- Theme: liberation, freedom, truth, growth
- Role direction: Liberator / Guardian / Wanderer
- Visual language: broken chains, wind/spirit motion, cyan-violet-gold luminous accents, horned mask/helmet silhouette, layered feather/fur/energy mantle and a spectral Spirit Form.

Radiant may be used as resonance/presentation language but is not a third core element unless separately approved through canon review.

## Anatomy lock
The corrected lower-body pass is authoritative for future production:
- exactly two readable legs
- balanced grounded stance
- coherent hips, knees, ankles, heels and toes
- armored/clawed feet may be stylized but cannot be fused, malformed or asymmetrically broken by generation artifacts
- no accidental extra limbs, digits or floating anatomy

Any earlier malformed-foot generation is reference-only and must not drive modeling, rigging, animation or publication art.

## Established ability candidates
- Chain Breaker
- Wind Walk
- Memory Whisper
- Echo Liberation

These names are preserved as current design candidates. Exact cooldowns, costs, status effects, damage/support values and multiplayer behavior remain NOT YET VERIFIED.

## Eco-Core / Eco-Essence terminology patch
Historical sheets used Eco-Core and Eco-Essence imagery. For current canon these may describe internal symbolism, resonance anatomy or non-extractable visual motifs only. They must never become removable sentient cores, creature fuel, ammunition, inventory items or harvesting rewards.

## Story/world integration
Candidate habitat/domain:
- borderlands and forbidden places
- high-altitude/cloud regions
- locations where old control systems or chains still affect people/Eco-Kin

Narrative function should test whether liberation can happen without replacing one form of control with another. Unbound should react strongly to coercive technology, forced labor, captivity and memory erasure.
