# DRYAD — Eco-Kin Production Reference

Status: **APPROVED-PENDING**
Implementation: **NOT YET VERIFIED**

## Identity

- Name: **Dryad**
- Class: **Humanoid-Kin**
- Working role: **Nature Guardian / Forest Memory Keeper**
- Primary element direction: **Flora**
- Secondary/resonance direction: **Radiant support potential**, pending balance and element review
- Habitat direction: ancient forests, nursery groves, overgrown ruins, sacred root sanctuaries, restoration-critical woodland zones

Dryad is part of the existing Echohearts roster pipeline. It does not replace Nature, Nurture, Verdant Matriona, or another established guardian identity.

## Visual production reference

Preserve the historical production reference traits:

- bark-textured humanoid body
- vine-like hair
- branching crown silhouette
- pointed ears
- pink blossoms
- moss and mushroom growth
- luminous chest seed/resonance motif
- enchanted-forest atmosphere

The chest motif is an **internal, non-extractable resonance symbol**. It is not a harvestable Eco-Core, crafting ingredient, ammunition source, or sellable resource.

## Gameplay direction

Dryad should connect to:

- ecological restoration
- purification support
- Sanctuary defense by consent
- healing/growth utility
- forest-balance encounters
- Harmony and Purity interactions
- woodland traversal/puzzle support where biologically and narratively appropriate

Any Sanctuary contribution uses **Sanctuary Aptitude / Partner Assist** rules. Dryad is not a worker unit.

## Production requirements

Before CANON implementation status:

1. Assign permanent EcoKinID and EchoprintID.
2. Complete silhouette and anatomy QA.
3. Confirm Flora/Radiant interaction without creating a new element.
4. Define Vibrance, Density, Harmony, and Purity values through the approved balancing process.
5. Define Kindling behavior, temperament, consent/refusal behavior, and Bond-memory hooks.
6. Define abilities, VFX, SFX, animation set, materials, and save-state fields through current UE5.8 data architecture.
7. Check originality and external-IP separation.
8. Connect at least one story mission, world-state consequence, and Sanctuary interaction.

## Art QA rule

Humanoid-Kin anatomy must remain coherent: two arms, two legs unless a specific canon body-plan exception is approved, readable hands/feet, coherent joints, no accidental duplicate appendages, no fused digits, and no text/image-generation artifacts.
