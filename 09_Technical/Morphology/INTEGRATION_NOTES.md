# Morphology Matrix — proposed implementation slice

- This branch is a review-only foundation; no production behavior enabled.
- 45 disabled rule slots are NOT invented lineage mappings. Populate only after reconciling the 125-ID permanent Dex, 1,120-name historical archive, and approved 18-element registry.
- Standard Eco-Kin may use Prime/Vector/Apex where approved. Nature's conditional Mutations override this lifecycle.
- Phenotype is one exclusive enum: Natural, Prismatic, or Obsidian. Overlays and scale remain orthogonal.
- Binary codec is versioned, bounded, CRC-checked, and rejects unknown versions; CRC is **not** cryptographic authentication. Cloud profiles require authenticated transport, server-side authorization, anti-replay, and conflict handling.
- Numeric attributes are the four canonical parameters only. Attribute limits and scaling are not assumed.
- Unreal Engine source is an integration candidate: relocate headers into the actual game module, resolve includes and module dependencies, compile with the project's installed UE version, and add roundtrip, corruption, truncation, and version-rejection tests.
- No third-party package import or build has been performed. Use only approved Epic-provided engine APIs and properly licensed assets.
