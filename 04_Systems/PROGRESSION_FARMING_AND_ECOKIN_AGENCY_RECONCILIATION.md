# Progression, Farming & Eco-Kin Agency Reconciliation

Status: **APPROVED SYSTEM DIRECTION / IMPLEMENTATION NOT YET VERIFIED**

Purpose: reconcile the reposted Somatic Affinity, Champion, Alpha, hunting/trapping, farming, storage, breeding and mutation material with the current Echohearts: Rebearth canon without creating a parallel game system.

## AI Mistake Patch / Continuity QA

The reposted material contains useful progression and activity ideas, but several parts conflict with current canon and are not carried forward unchanged.

### Retired or transformed concepts

- **Eco-Kin as modular combat frames** → retired. Eco-Kin are autonomous sentient partners.
- **Somatic Affinity as neural/genetic rewrite XP** → historical prototype language only. Keep the useful idea of progression earned through combat, restoration, exploration and cooperation, but do not frame Eco-Kin as hardware being overwritten.
- **Rank-30 reset / polarity stamping / Forma-like resets** → retired. No level-reset loop that wipes an Eco-Kin back to zero.
- **Bio / Kinetic / Matter as the core elemental taxonomy** → retired. The locked 12 elements remain Solar, Lunar, Hydro, Magma, Aero, Flora, Volt, Terra, Iron/Tech, Spirit, Chaos, Radiant.
- **Capture cages, snares, pitfalls, harpoons, containment boxes, pheromone lures and forced suppression** → retired as player progression. Tracking, observation, bait placement, rescue tethers and stabilization gear may remain only when they serve welfare, rescue, relocation or voluntary Kindling opportunities.
- **DNA Fusion / donor consumption / sacrifice / genome extraction** → retired. Replace with ethical **Growth Rites, Resonance Trait Infusion, Bio-Synergy Weaving, Primal Reversion** and other non-destructive adaptation systems.
- **Forced mutation catalysts** → retired. Adaptation is voluntary/earned and must preserve Eco-Kin identity.
- **Sentient storage-as-items or stasis imprisonment** → retired. Use Sanctuary/Haven residency and roster assignment instead.
- **Breeding station as a player-controlled production machine** → retired from core canon. Natural lifecycle/Echo-Egg care may exist where established, but the player does not industrialize sentient reproduction.

## Canon progression stack

Echohearts progression is separated into layers so one meter does not try to represent identity, combat skill and relationship at the same time.

### 1. Kindling

**Kindling = the emotional bond created with an Eco-Kin.**

Raised by:
- protecting each other
- restoring damaged ecosystems
- care and recovery
- exploration and camping
- resolving Eco-Kin-specific quests
- respecting refusal/retreat decisions
- successful cooperative combat

Kindling should unlock relationship dialogue, trust behaviors, Command Sync options, voluntary Growth Rite eligibility, Sanctuary preferences and signature partner interactions.

### 2. Field Mastery / Growth Experience

Working name: **Field Mastery**. Final public naming remains pending UX/canon review.

This replaces the useful leveling function of Somatic Affinity without the “combat frame” framing.

Earned from:
- meaningful combat participation
- restoration objectives
- rescue/tracking missions
- exploration discoveries
- Sanctuary/community work
- cooperative squad actions

No kill-only requirement. No reset-to-zero prestige loop.

### 3. Growth Rites / Resonance Adaptation

Evolution/adaptation occurs through established Growth Rites and resonance conditions rather than forced DNA mutation.

Possible triggers:
- biome attunement
- Kindling threshold
- completed story/behavior milestone
- environmental restoration state
- safe catalyst/relic interaction
- time/weather/celestial condition
- Eco-Kin choice/consent

Branches are allowed, but they must preserve recognizable identity and use the locked 12 elements.

## Battle roster rules

### Campaign / PvE

- **Field roster:** up to **8 Eco-Kin**.
- **Simultaneously active in real-time combat:** **3 Eco-Kin**.
- Remaining roster members are reserve/support and can rotate through valid combat rules.
- Duplicate roster entries are not used for standard campaign battle squads unless a future mode explicitly overrides this.

### PvP / Resonance Arena

- **6v6** roster format.
- PvP remains simulation-safe and separate from overworld griefing.
- Balance uses Harmony Circuit / Resonance Arena rules rather than copying campaign encounter assumptions.

## Champion / advanced-role material

The reposted Velo-Stalker, Giga-Carapace and Volt-Weaver concepts are retained as **combat-role archetype references**, not a new elemental taxonomy and not a separate species class.

Translation examples:
- **Velo-Stalker concept** → fast striker / ambush archetype using Aero, Volt, Flora, Spirit or other canon elements as appropriate.
- **Giga-Carapace concept** → defender / bastion archetype using Terra, Iron/Tech, Hydro or Flora as appropriate.
- **Volt-Weaver concept** → control / chain-effect caster archetype using Volt plus a compatible canon secondary element.

Each actual Eco-Kin keeps its own biology, identity and evolution line. Archetypes describe combat role, not ownership tier.

## Large guardian / Alpha encounter material

Useful boss-scale ideas are retained, but the capture/extraction loop is removed.

Allowed encounter structure:
- territorial guardian or Blight-distressed large Eco-Kin
- multi-phase combat or environmental challenge
- Break/guard windows where appropriate
- visible biome reactions
- restoration/calm/purification objective
- retreat, rescue or nonlethal completion state
- reward from purified deposits, shed material, restored ecology, archives or faction support

Not allowed:
- harpoon-and-cage capture progression
- forced genome extraction
- suppressing sentient cores for ownership
- killing rare guardians as the only progression path

Existing **Titan** classification should be preferred when scale/story significance qualifies.

## Tracking and encounter preparation

Keep the grounded fieldcraft, remove coercive capture.

Core loop:

**Track spoor / signs → scan habitat → prepare safe observation area → place food/water or calming environmental aid → approach carefully → protect/calm/stabilize → Kindle / Release / Defer / Treat / Relocate**

Useful tracking clues:
- prints
- disturbed soil
- scratched bark
- feathers/fur/shed scales
- bioluminescent residue
- water disturbance
- feeding remains
- Blight residue

Food decay/spoilage can remain as an ecology/survival simulation mechanic, but it should influence wildlife behavior and resource quality, not function primarily as a sentient-capture exploit.

## Farming / Sanctuary productivity loop

Core activities retained:
- seeding
- watering
- harvesting
- wood gathering and processing where ecologically permitted
- livestock care where appropriate
- crafting/processing
- resource delivery
- soil care
- guard/watch duty
- weather preparedness
- community supply support

### Voluntary Eco-Kin task assignment

Eco-Kin may **voluntarily assist** with Sanctuary tasks through their established aptitudes. They are not labor inventory.

Current aptitude examples:
- Garden Care
- Water Care
- Repair Help
- Stone Work
- Scout Watch
- Comfort
- Defense
- Archive Help

Task assignment must respect:
- Harmony/Kindling
- health and sickness
- fatigue/rest
- habitat comfort
- individual preference
- temporary refusal

## Economy and production

Farming/resource activity may support:
- local trade
- Sanctuary upkeep
- community rebuilding
- crafting
- Care Grant Economy / Community Supply Crates
- regional restoration contracts

“Gold” from older drafts remains **currency proposal language** until reconciled against the final economy/currency canon.

## Eco-Kin care and sickness

Retained:
- sickness and injury states
- contaminated food/water effects
- exhaustion
- biome hazards
- Blight exposure
- recovery herbs/treatments
- Nurse/Recovery Specialist support
- Healing Incubator for injury, Blight stabilization, Echo-Egg care, Spirit Load and Growth Rite support

The Healing Incubator is **not** a breeding/cloning machine.

## Residency / roster management instead of sentient storage

Historical “Kin Vault” language is replaced by a **Sanctuary/Haven Registry** model.

The player manages:
- current field roster
- PvP roster
- Sanctuary residents
- temporary recovery residents
- Havenlink relocation cases
- task volunteers
- expedition volunteers

Eco-Kin are physically present in appropriate Sanctuary/Haven spaces rather than converted into inventory items.

## Unique guardian / legendary rule

Unique guardian-level Eco-Kin may be one-of-a-kind story encounters. They are not bred, cloned or traded as commodities.

Bonding eligibility is story-specific. Some guardians may assist, ally, teach or travel temporarily without becoming a normal roster resident.

## Technical implementation posture

The reposted C++, Python and pseudo-engine code is **NOT YET VERIFIED** and should not be implemented as-is.

Current production rule:
- data/Blueprint-first when sufficient
- C++ only for an actual architecture/performance/networking need
- no duplicated Unity/Python runtime architecture inside the UE5 production path
- no client-authoritative progression rewards
- no unverified code labeled production-ready

The useful technical principles to retain are:
- pooled VFX where profiling proves churn is costly
- event-driven progression updates instead of unnecessary per-frame polling
- authoritative server validation for multiplayer progression
- stable EcoKinID references rather than display-name coupling
- deterministic reward accounting and save migration support

## Player-facing loop

**Explore → Observe/Track → Protect/Calm/Kindle → Battle/Restore → Gather ethically → Build/Farm → Invite voluntary Eco-Kin help → Produce/Trade/Support community → Care/Recover → Upgrade Sanctuary → Unlock more helper capacity/regions → Advance story → Face larger restoration crises**

This loop is the canonical replacement for the older capture/fusion/forced-mutation economy.
