Status: DESIGN QA RUBRIC, NOT A CLAIM OF PLAYER-TEST RESULTS.

## Core Satisfaction Areas
Score each area 1–5 only when evaluating a concrete build, mockup, asset set or playtest result.

- World/environment visuals
- Main character presentation
- Human NPC presentation
- Eco-Kin presentation
- Animation quality/readability
- Buttons and UI interactions
- Combat readability
- Exploration quality
- Sanctuary/base interaction
- Story clarity/emotional connection
- Wild behavior credibility
- Restoration consequence visibility
- Mini-game usefulness and replayability
- Performance/stability
- Accessibility

## Heart Statement Questions
Every playtest should ask:
1. Did the world feel like it needed your help?
2. Did Eco-Kin feel like living beings instead of inventory objects?
3. Could you clearly see how your choices changed Rebearth?

## UI Questions
- Could you identify Scan, Calm/Care, Eco-Kin Command and Field Tool actions quickly?
- Were mission goals clear?
- Did menus expose too many systems at once?
- Could you use important interactions with keyboard/controller without confusion?
- Were danger, rescue and restoration actions equally discoverable?

## Mini-Game Questions
For every mini-game:
- Did it teach or deepen a core Echohearts system?
- Was the input readable on first use?
- Was failure understandable and fair?
- Did the reward connect to the main game?
- Did it feel optional/replayable where appropriate rather than mandatory busywork?
- Were reduced-motion/audio/contrast alternatives available where needed?

## Visual/Animation Questions
- Can each major region be recognized from one screenshot?
- Can players read an Eco-Kin's calm, fear and defensive state from animation/body language?
- Do Blight, healthy Rebearth and restoration states read as distinct visual languages?
- Are high-cost VFX readable rather than noisy?

## Evidence Rule
Do not label these scores as player satisfaction unless they come from actual playtest/survey data. Internal design estimates must be labeled INTERNAL REVIEW only.
