# Standalone Eco-Kin Image Queue — 2026-09-20

Status: ACTIVE ART INTAKE / ONE ECO-KIN PER IMAGE

This queue converts historical batch requests into the current Echohearts art-production rule: **one standalone, full-body Eco-Kin at a time**. No lineup grid, no multi-character poster used as final model reference, and no generated text treated as canon without QA.

## Global image standard
Every image must:
- show one primary Eco-Kin full-body unless an explicit duo scene is canon-required;
- preserve coherent anatomy and correct limb/digit/wing/tail counts;
- read clearly at gameplay distance;
- avoid generic armored dragon/lion/wolf defaults;
- use a body plan, movement language and material language that make sense for its ecology;
- use Ancient Tech only when lore requires it;
- avoid direct visual copying of other franchises;
- avoid text artifacts, misspellings and accidental extra anatomy;
- use the exact approved name on-image only when a named presentation card is intentionally requested;
- keep completed approved artwork as production reference unless a correction is explicitly required.

## Required approval labels
Every image/result must end in exactly one status:
- CANON
- APPROVED-PENDING
- MERGED/RENAMED
- RETIRED/REFERENCE-ONLY
- REJECTED

## Art QA checklist
Species DNA → silhouette → limb count → digit count → joint direction → eyes → ears → wings/fins → tail count → symmetry → surface/material logic → rig feasibility → locomotion feasibility → collision feasibility → VFX readability → color-blind readability → name/text accuracy → approved-reference comparison.

Failed anatomy does not become lore. It goes to `99_Reference_Retired_Needs_Redesign`.
