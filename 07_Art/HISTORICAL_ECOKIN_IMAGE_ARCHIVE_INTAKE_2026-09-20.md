## File naming target
Use stable, descriptive names rather than opaque chat IDs when identity is known:
`<EcoKinName>__<FormOrPurpose>__<SourceDate>__<VariantIndex>.png`

Examples:
- `Glow_Worm__Base_Concept__2026-06-08__01.png`
- `Stump__Rooted_Guardian_Concept__2026-06-17__01.png`
- `Moth__Transformation_Reference__2026-06-XX__03.png`

Never rename a file in a way that fabricates a canon identity not supported by the source.
