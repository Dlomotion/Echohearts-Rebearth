# ECO-KIN CREATION CHAT — VISUAL SOURCE RULE

**Status:** CANON production-art workflow rule

## Source-of-truth behavior

Existing approved Eco-Kin images from the user's prior **Eco-Kin Creation / Echohearts character-design chats** are production references for future image creation in this project.

When a previously created Eco-Kin already has approved art, future art must begin from that established identity rather than inventing a different creature with the same name.

Priority order:

1. newest explicit user correction;
2. locked / approved creature image;
3. approved anatomy, DNA, silhouette, colors, materials, gear and biome;
4. established gameplay/story canon;
5. older draft art;
6. unapproved / malformed generations.

## Image consistency rule

For a returning Eco-Kin, preserve as applicable:

- species DNA / body plan;
- head and facial structure;
- eye count / eye color;
- limb, digit, wing, tail and horn counts;
- body proportions and scale;
- core palette and markings;
- Ancient Tech placement and material language;
- elemental / resonance features;
- clothing / gear where canon;
- evolution-stage continuity;
- biome / ecological identity;
- permanent name spelling.

Do not change those merely to create novelty.

## Quality-control rule

Correct only what is wrong unless a redesign is explicitly requested. Typical valid corrections include:

- extra or missing limbs / digits / wings / tails;
- fused or malformed anatomy;
- wrong name or `Echo-Kin` / `Eko-Kin` text instead of **Eco-Kin**;
- text artifacts;
- incorrect element iconography;
- accidental poster drift;
- off-model face / proportions;
- inconsistent evolution anatomy;
- duplicated accessories;
- lighting/background problems that obscure the character.

Rejected or malformed images remain reference/provenance assets and never overwrite approved art.

## New image creation rule

When creating a genuinely new Eco-Kin:

- one Eco-Kin per image unless the user explicitly asks for a lineup;
- full-body silhouette must be readable;
- ecological / biological logic comes before fantasy decoration;
- animal Eco-Kin keep coherent animal anatomy;
- Humanoid-Kin remain restricted to intentional approved humanoid concepts;
- Ancient Tech must look grown into / respectfully fitted to anatomy, not generic pasted-on armor;
- do not copy another franchise's creature, costume, composition, logo or protected character identity;
- use an original Echohearts visual language: stylized readability, cinematic Unreal-quality material treatment, living ecological detail, archaeological Ancient Tech and biome-matched presentation.

## Dark Beasts / Ancient Beasts

Dark Beast and Ancient Beast images follow the same consistency rule. Category treatment may affect atmosphere, materials and resonance VFX, but must not erase the creature's individual DNA or turn every member into the same black-armored or ruin-armored silhouette.

- **Dark Beast visual language:** nocturnal / spectral / abyssal / anomaly cues, fracture or corruption only when lore supports it, restrained shadow rhythm, distinct underlying biology still visible.
- **Ancient Beast visual language:** age, geological wear, extinct ecology, relic symbiosis, old-world materials and archaeological resonance; not generic ornate armor by default.

## Current-chat behavior

When the user requests an image here for an already-created Eco-Kin, locate and reuse the approved prior reference when it is available in the project/library/current conversation. If the actual source image is not available to the image-editing tool, do not pretend to edit it; use its recovered design record for a new matching generation or ask for the actual image only when an exact edit is required.
