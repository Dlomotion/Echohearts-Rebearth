The historical Eco-Kin Creation Batch archive contains many generated image links and named batch cards, but the approved binary source images are not yet stored in this repository branch. This queue controls recovery and prevents low-quality or contradictory generated art from becoming production reference by accident.

## Recovery Priority
Recover images only when the corresponding Eco-Kin or batch is entering active canon review. Do not bulk-promote hundreds of historical images into production without QA.

Priority order:
1. already user-approved or repeatedly referenced Eco-Kin,
2. duplicate/collision families requiring visual comparison,
3. concepts filling a real current roster gap,
4. concepts tied to an active region/mission,
5. remaining archive material.

## Required Metadata Per Recovered Asset
- historical batch/range
- proposed Eco-Kin name
- source image filename/link reference
- source date if available
- source chat/thread
- current canon status
- current EcoKinID if assigned
- body-plan description
- proposed habitat
- old element labels
- current element mapping status
- duplicate/collision notes
- anatomy QA status
- originality/IP review status
- art lead decision

## Art QA Gate
Each recovered image must pass:
- one readable creature identity,
- coherent limb count and joints,
- coherent animal body plan unless explicitly Humanoid-Kin,
- no extra arms/fingers/legs/wings/tails,
- no fused or duplicated anatomy artifacts,
- no unreadable silhouette caused by VFX,
- no accidental text/logo/signature artifacts,
- no obvious outside-franchise costume/mascot/logo copying,
- current Echohearts visual language,
- current element readability after mapping,
- animation-feasible anatomy,
- material/VFX notes suitable for UE5 production.

## Duplicate Visual Comparison
When two historical entries share a name or near-identical role, place their images side by side during review and answer:
1. Are they actually the same design lineage?
2. Which silhouette is strongest?
3. Which anatomy is most coherent?
4. Which ecological niche is more useful?
5. Can useful traits be merged without producing a cluttered design?
6. Should one become a regional form, separate species, renamed species, or be retired?

## Regeneration Rule
Do not regenerate simply because old art is imperfect. First determine whether the concept is worth preserving. If regeneration is required, preserve the approved silhouette, anatomy, body plan, palette logic, key identifying features, and composition goals unless the canon review explicitly calls for redesign.

## Production Output For Approved Eco-Kin
Final art package should include:
- front
- side
- back
- three-quarter hero view
- scale chart
- expression/behavior set
- calm/fear/defensive states
- movement notes
- material callouts
- element/VFX callouts
- anatomy sheet
- animation risks
- one clean publication key art image
